Política de Privacidade

CyanBot • Última atualização: 7 de agosto de 2026

Esta política explica quais informações o CyanBot ("o Bot", "nós") coleta ao ser usado no Discord, por que coletamos, e como você pode solicitar a remoção delas.

1. Que dados coletamos

O Bot só coleta dados gerados pelo uso normal dos seus comandos. Não lemos nem armazenamos o conteúdo geral das suas mensagens — apenas o que é necessário para cada funcionalidade abaixo.

DadoOnde é usado
ID do usuário (Discord)Sistema de XP/nível, saldo de moedas, inventário, avisos (warns), sorteios e autorização de comandos
ID do servidor (Discord)Separar configurações, rankings de XP e logs de moderação entre servidores diferentes
XP, nível e contagem de avisosComandos !level, !rank, !perfil, !warn, !clearwarns
Cyan Coins, histórico de Daily, transferências e inventárioSistema de economia (!moedas, !daily, !pay, !coinflip, !loja) e salvamento de templates comprados
Dados do Perfil (Sobre Mim, URL do fundo, cores RGB, Spotify URL)Personalização visual do cartão de perfil (!perfil, !setbg, !setspotify, !removespotify)
IDs de canais e cargos configuradosComandos de configuração como !levelcanal, !levelmsg e !antispam
Dados de sorteios (prêmio, participantes, horário)Comando /giveaway
Imagens enviadasComando !sayembed — processadas instantaneamente no envio e descartadas em seguida

2. Como coletamos

Todos os dados vêm diretamente da API do Discord no momento em que você usa um comando do Bot — nunca monitoramos mensagens fora dos comandos, exceto pela verificação técnica necessária para a contabilização do sistema de XP (que verifica o envio de mensagens para somar pontos e aplicar o bônus de Booster, sem salvar o texto das mensagens).

3. Serviços de terceiros

Algumas funcionalidades do Bot dependem de serviços externos. Ao usar esses comandos, dados relevantes (nunca sua identidade pessoal do Discord) são enviados ou redirecionados a eles:

  • Discord Gateway & Status (Spotify) — lê os metadados de mídia tocados ao vivo no aplicativo do Spotify quando o usuário ativa o status de presença no Discord (!status).
  • AniList GraphQL API — recebe as consultas de busca ao usar comandos de anime, mangás e personagens (!wikianime, !manga, !personagem, !animeseason, !agenda).
  • Gifukai API & Tenor API — fornecem os GIFs animados de roleplay e ações entre membros (!abracar, !beijar, !soco, !slap, !pat, !morder, !dancar, !cutucar, !lamber).
  • Google Tradutor (via biblioteca deep-translator) — traduz sinopses e biografias para o português com fallback limpo de segurança.
  • LivePix — plataforma externa segura para doações voluntárias de apoio via Pix (!apoie).

Recomendamos consultar as políticas de privacidade desses serviços se tiver dúvidas sobre como eles tratam os dados que recebem.

4. Onde os dados ficam armazenados

Os dados persistentes (XP, saldo de Cyan Coins, inventário de templates, avisos, configurações de servidor, etc) são armazenados em um banco de dados local SQLite (cyanbot.db) no servidor de hospedagem segura do Bot. Não vendemos, alugamos ou compartilhamos esses dados com terceiros para fins de publicidade ou marketing.

5. Por quanto tempo guardamos os dados

Os dados ficam armazenados enquanto o Bot estiver no servidor e a funcionalidade correspondente estiver em uso. Administradores e usuários podem remover dados específicos a qualquer momento através dos próprios comandos do Bot (por exemplo, !removespotify, !clearwarns, /giveaway_clear). Se o Bot for removido de um servidor, os dados associados àquele servidor podem ser apagados periodicamente.

6. Seus direitos

Você pode solicitar a exclusão dos seus dados armazenados pelo Bot entrando em contato com o desenvolvedor (veja seção 8). Faremos o possível para atender pedidos de exclusão dentro de um prazo razoável.

7. Crianças

O uso do Discord (e, por consequência, deste Bot) é regido pelos Termos de Serviço do Discord, que exigem idade mínima. Não coletamos intencionalmente dados adicionais de menores além do que a própria plataforma Discord já processa.

8. Contato

Dúvidas sobre esta política ou pedidos de remoção de dados podem ser feitos ao desenvolvedor do Bot: skky0001 (via Discord).

9. Alterações a esta política

Esta política pode ser atualizada conforme o Bot ganha novas funcionalidades. Mudanças relevantes serão refletidas na data no topo desta página.

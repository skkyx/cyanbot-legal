Política de Privacidade

CyanBot • Última atualização: 13 de agosto de 2026

Esta política explica quais informações o CyanBot ("o Bot", "nós") coleta ao ser usado no Discord, por que coletamos, e como você pode solicitar a remoção delas.

1. Que dados coletamos

O Bot só coleta dados gerados pelo uso normal dos seus comandos. Não lemos nem armazenamos o conteúdo geral das suas mensagens — apenas o que é necessário para cada funcionalidade abaixo.

2. Como coletamos

A maior parte dos dados vem diretamente da API do Discord no momento em que você usa um comando do Bot — nunca monitoramos mensagens fora dos comandos, exceto pela verificação técnica necessária para a contabilização do sistema de XP (que verifica o envio de mensagens para somar pontos e aplicar o bônus de Booster, sem salvar o texto das mensagens). Os dados relacionados ao Dashboard Web são coletados apenas quando você opta por fazer login nele (veja a próxima seção).

3. Dashboard Web (Login com Discord)

O Dashboard Web é um site separado, acessado pelo navegador, para gerenciar Reaction Roles sem precisar usar comandos no Discord. Ele usa o sistema oficial de login OAuth2 do Discord — nunca vemos ou armazenamos sua senha.

DadoPor quê
ID, nome de usuário e avatar do DiscordIdentificar você e exibir seu nome/foto no Dashboard
Lista de servidores em que você está e suas permissões nelesDescobrir em quais servidores você é admin e o CyanBot está presente, pra mostrar só esses no Dashboard

Cookie de sessão do navegadorManter você logado no Dashboard entre uma página e outra

Os tokens de OAuth2 e o cookie de sessão ficam guardados temporariamente (até 7 dias ou até você clicar em "Sair", o que ocorrer primeiro) e são apagados automaticamente depois disso. Eles nunca são compartilhados com terceiros.

4. Serviços de terceiros

Algumas funcionalidades do Bot dependem de serviços externos. Ao usar esses comandos, dados relevantes (nunca sua identidade pessoal do Discord) são enviados ou redirecionados a eles:

  • Discord Gateway & Status (Spotify) — lê os metadados de mídia tocados ao vivo no aplicativo do Spotify quando o usuário ativa o status de presença no Discord (!status).
  • AniList GraphQL API — recebe as consultas de busca ao usar comandos de anime, mangás e personagens (!wikianime, !manga, !personagem, !animeseason, !agenda).
  • Gifukai API & Tenor API — fornecem os GIFs animados de roleplay e ações entre membros (!abracar, !beijar, !soco, !slap, !pat, !morder, !dancar, !cutucar, !lamber).
  • Google Tradutor (via biblioteca deep-translator) — traduz sinopses e biografias para o português com fallback limpo de segurança.
  • LivePix — plataforma externa segura para doações voluntárias de apoio via Pix (!apoie).

Recomendamos consultar as políticas de privacidade desses serviços se tiver dúvidas sobre como eles tratam os dados que recebem.

5. Onde os dados ficam armazenados

Os dados persistentes de economia, XP, avisos e configurações de servidor (XP, saldo de Cyan Coins, inventário de templates, avisos, etc) são armazenados em um banco de dados local SQLite (cyanbot.db) no servidor de hospedagem do Bot. Os dados de perfil, os painéis de Reaction Roles e as sessões do Dashboard Web ficam num banco de dados Redis, compartilhado apenas entre o Bot e o Dashboard — ambos hospedados de forma segura pela mesma equipe, sem acesso de terceiros. Não vendemos, alugamos ou compartilhamos nenhum desses dados com terceiros para fins de publicidade ou marketing.

6. Por quanto tempo guardamos os dados

Os dados ficam armazenados enquanto o Bot estiver no servidor e a funcionalidade correspondente estiver em uso. Administradores e usuários podem remover dados específicos a qualquer momento através dos próprios comandos do Bot (por exemplo, !removespotify, !clearwarns, /giveaway_clear) ou apagando um painel de Reaction Role pelo Dashboard. Sessões e tokens do Dashboard Web expiram automaticamente em até 7 dias, ou imediatamente ao clicar em "Sair". Se o Bot for removido de um servidor, os dados associados àquele servidor podem ser apagados periodicamente.

7. Seus direitos

Você pode solicitar a exclusão dos seus dados armazenados pelo Bot entrando em contato com o desenvolvedor (veja seção 9). Faremos o possível para atender pedidos de exclusão dentro de um prazo razoável.

8. Crianças

O uso do Discord (e, por consequência, deste Bot e do Dashboard) é regido pelos Termos de Serviço do Discord, que exigem idade mínima. Não coletamos intencionalmente dados adicionais de menores além do que a própria plataforma Discord já processa.

9. Contato

Dúvidas sobre esta política ou pedidos de remoção de dados podem ser feitos ao desenvolvedor do Bot: skky0001 (via Discord).

10. Alterações a esta política

Esta política pode ser atualizada conforme o Bot e o Dashboard ganham novas funcionalidades. Mudanças relevantes serão refletidas na data no topo desta página.
